1. Purpose

YHWRKS provides tools for authorized overseas ecommerce market analysis and growth diagnostics. This policy explains how information is handled when users authorize access to Google services used by the application.

2. Google user data we access

When an authorized user connects a Google account, the application may use OAuth credentials and Google Ads account identifiers necessary to request the Google Ads API functions selected by the user. For keyword research, this can include keyword-planning and historical keyword metrics available through the authorized Google Ads account.

3. How data is used

Google user data is used only to provide the requested analysis and related internal or authorized client research. The application does not use Google user data for unrelated advertising, user profiling, or resale.

4. Storage and security

OAuth credentials and access tokens are treated as confidential. They are kept out of public source code and public reports. Analysis artifacts retain only the information necessary for the research workflow and evidence traceability.

5. Sharing

Google user data is not sold. Any service-provider processing necessary to operate the application must be limited to the functions required to provide the service and handled consistently with this policy.

6. Retention and deletion

Data is retained only for as long as necessary for the authorized research purpose, legal obligations, security, or operational requirements. Authorized users may request deletion of applicable stored data through the contact channel above.

7. Access revocation

Users can revoke Google account access through their Google Account security settings. Revoking access prevents future API access using the revoked authorization.

8. Changes

This policy may be updated when the application, data flows, or legal requirements change. The current version will be published at this URL.
