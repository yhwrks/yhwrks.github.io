# Security Policy

This repository is intentionally public and is limited to public website content for yhwrks.com.

Do not place private project material, client data, authentication material, or local-only configuration in this repository.

If sensitive information is accidentally exposed, revoke or rotate it first, then remove it from the repository and history as appropriate.

For security-related contact, use ikegami@no-boundary.com rather than posting sensitive details in a public issue.
