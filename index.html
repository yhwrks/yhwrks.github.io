YHWRKS

YHWRKS develops evidence-based tools for overseas ecommerce market analysis and growth diagnostics.

What this application does

The application helps authorized users research overseas ecommerce opportunities by organizing market, search, competitive, and performance evidence. Where an authorized Google Ads account is connected, the application can use Google Ads API keyword-planning data such as historical keyword metrics to support market research.

Who it is for

The application is intended for YHWRKS and authorized client research. It is not a public advertising platform and does not sell Google user data.

Data handling

Google account and Google Ads access is used only for the functions the authorized user requests. Credentials and access tokens are treated as confidential and are not published in project source code or public reports.

YHWRKS Overseas EC Analysis is operated by No Boundary LLC.
